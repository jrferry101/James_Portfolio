My Projects.

Microsoft

At Microsoft I built a release planner that assisted every Azure service in creating an API specification and generating SDKs based on this API specification.
I was told by my manager that I was doing better quality work in less time than the principal level product manager I replaced. I was quickly put in charge of many AI projects and I developed many AI agent workflows including one which would allow a developer to circumvent this entire release planner to generate and release their SDKs only using Copilot in Visual Studio Code. Also included on slide 7 above is an image of an AI agent workflow I created that replaced manual SDK code reviews with a system that would learn from feedback. At We Care Insurance I used Figma to design from scratch a working minimum viable product that I delivered to full stack developers to encode. The images in the slideshow below are just a few examples of the user experiences I designed.
