# James Ferry — Portfolio Site

A personal portfolio site showcasing my product management work across Adobe, Microsoft, We Care Insurance, and Global Payments.

## About

I conceived and designed this site from scratch — the layout, visual hierarchy, content strategy, copy, and every interaction detail. I then used [Claude Code](https://claude.ai/code) to vibe code the full implementation through natural conversation, shipping a polished, production-ready site without writing a single line of code manually. This project is itself a demonstration of how I use AI: not as a shortcut, but as a force multiplier that lets me move faster and think bigger.

## What's inside

- **Home** — intro and background on my product management journey
- **Work Projects** — slideshows and write-ups covering my time at Adobe, Microsoft, We Care Insurance, and Global Payments
- **AI Passion Projects** — personal AI experiments and side projects
- **About + Connect** — more about me and how to reach me

## Tech

Hand-crafted HTML, CSS, and vanilla JavaScript — no frameworks, no build tooling, no dependencies. Custom-built slideshow engine with autoplay, fade transitions, and responsive controls. Scroll-aware navigation with mobile hamburger menu. Hosted as a static site.

## Built with

- **Claude Code** — AI-powered CLI used to design and ship the entire site through conversation
- **Figma** — used for design work on client projects featured in the portfolio
