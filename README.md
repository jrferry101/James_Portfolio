# James Ferry — Portfolio Site

A personal portfolio site showcasing my product management work across Adobe, Microsoft, We Care Insurance, and Global Payments.

## About

I designed everything on this site myself — the layout, content, copy, and visual structure — and used [Claude Code](https://claude.ai/code) to vibe code the entire implementation. This included building a static copy of my Weebly site with full feature parity, adding custom JavaScript for slideshows and navigation, and iterating on mobile responsiveness and UI polish through natural conversation with Claude.

## What's inside

- **Home** — intro and background on my product management journey
- **Work Projects** — slideshows and write-ups covering my time at Adobe, Microsoft, We Care Insurance, and Global Payments
- **AI Passion Projects** — personal AI experiments and side projects
- **About + Connect** — more about me and how to reach me

## Tech

Plain HTML, CSS, and vanilla JavaScript — no frameworks, no build step. Hosted as a static site.

## Built with

- **Claude Code** — AI-powered CLI used to implement the entire site through conversation
- **Figma** — used for design work on client projects featured in the portfolio
